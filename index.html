画面预览（拖动鼠标框出 slide 区域，不框就截整个画面）

点上面的 ① 按钮，在弹窗里选：
“Chrome 标签页” → Zoom 网页版所在的标签页
或 “窗口” → Zoom 桌面客户端
选好后这个页面可以放到后台，切去做别的事

灵敏度 = 画面有多少比例变化才算换页。逐条出现的要点没截到 → 调小；人像视频/鼠标老是误触发 → 调大，或框选时避开视频区域。

  1. 选标签页时，Zoom 那个标签页不用在最前面，切到别的标签页也照样截。
  2. 选窗口时，Zoom 窗口被别的窗口挡住没关系，但不要最小化（最小化后 Windows 不再绘制画面）。
  3. 这个截图页面本身也不要关掉。点“自动存到文件夹”后，每张会立即存盘，万一浏览器崩了也不丢。
