# Zoom Slide 自动截图

在浏览器里自动截取 Zoom 会议共享的 slides：只在换页时保存一张，翻回旧页不重复存，可导出 PDF。Zoom 标签页/窗口不用放在最前面。

**在线使用：** https://cccccbt.github.io/zoom-slide-capture/

## 用法
1. 用 Chrome 或 Edge 打开上面的链接（Safari 不支持）。
2. 点「① 选择要截的 Zoom 标签页 / 窗口」：
   - Zoom 网页版 → 选「Chrome 标签页」
   - Zoom 桌面版 → 选「窗口」（可被遮挡，但不要最小化）
3. 在预览上拖框，只框住 slide，避开人像视频。
4. 建议点「自动存到文件夹…」，每张立即存盘；结束后可「下载 PDF」。

Mac：选「窗口」需先在 系统设置 → 隐私与安全性 → 录屏与系统录音 里允许 Chrome。

所有处理都在本地浏览器完成，截图不会上传到任何服务器。
